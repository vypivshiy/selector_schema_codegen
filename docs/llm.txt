# ssc_codegen — KDL Schema DSL v2.1 Reference (v0.44.0)

## 1. Header & Compiler Pipeline

`ssc_codegen` compiles `.kdl` (KDL 2.0) scraping and REST API schemas into standalone, zero-framework parsers and typed HTTP clients.

- **Compiler Pipeline**: `.kdl schema -> kdlquery CST -> 5-pass core (import resolution -> structural lint -> cross-ref lint -> AST build -> pipeline type check) -> target visitor -> generated code`
- **Top-Level Nodes**: `@doc "..."`, `import`, `define`, `extension`, `json`, `(array)json`, `(dict)json`, `struct`, `(item|list|dict|table|flat|rest|raw)struct`, `fn`, `(raw)fn`.
- **Declaration Order Invariant**:
  - **Intra-file (Top-Down)**: Local `struct` and `json` definitions referenced via `nested`, `jsonify`, or schema fields must be declared **above** their callers (`E302`).
  - **Inter-file (`import`)**: Explicitly imported symbols and their private transitive dependency closure are topologically sorted automatically.

| Target | CLI Subcommand | HTML / DOM Backend | JSON Strategy | HTTP Client (`--http-client`) | Runtime & I/O Options |
|---|---|---|---|---|---|
| **Python** | `generate python` | `bs4` (default; `--bs4-parser lxml\|html.parser\|html5lib`), `lxml`, `parsel`, `slax` | `TypedDict` + allowlist projectors | `httpx`, `httpx2` (auto-fallback to `httpx`), `aiohttp`, `requests` | `--http-io both\|sync\|async`; optional `-R` (`--separate-runtime`) + `-rn <name>` |
| **JavaScript** | `generate js` | Vanilla DOM API (`querySelector`, `document.evaluate`) | JSDoc `@typedef` + allowlist projectors | `fetch`, `axios` | ESM module + `.d.ts` |
| **Go** | `generate go` | `goquery` | `struct` + `gjson` allowlist projectors | `net/http` (stdlib) | Emits shared `sscgen_runtime.go` |
| **Rust** | `generate rust` | `dom_query` | `serde` / `serde_json` + allowlist projectors | `reqwest` (async) | Emits shared `sscgen_runtime.rs` |

## 2. Module Declarations (`import`, `define`, `extension`)

### 2.1 `import`

Syntax: `import "<relative_path.kdl>" { (<kind>)<SymbolName>; ... }`

- Block is **mandatory and non-empty** (`E003`). Path-only and bare-name imports are forbidden (`E003`).
- Every symbol requires a kind tag: `(extension)`, `(struct)`, `(json)`, `(define)`, or `(fn)` (`E003`).
- Paths resolve relative to the importing file. Imports are **private** (never implicitly re-exported) and automatically pull their private dependency closure into codegen. Cyclic imports (`E003`/`E300`) and symbol collisions (`E003`) are errors.

```kdl
import "./shared.kdl" {
    (extension)Utils
    (struct)Book
    (json)ApiResponse
    (define)PRICE-REGEX
    (fn)clean-title
}
```

### 2.2 `define`

- **Naming**: Must be `UPPER_CASE` matching `^[A-Z_][A-Z0-9_-]*$` (`E002`).
- **Scalar define**: `define KEY="value" [KEY2="value2" ...]` — substituted when `KEY` is passed as an operation argument or `@request` argument. Scalar defines may interpolate earlier defines via `{{UPPER_NAME}}`; lowercase `{{param}}` inside a define string is preserved untouched as a runtime `@request` placeholder (note: `{{UPPER_NAME}}` is not interpolated directly inside `@request "..."` literals — compose the URL in a `define` first, `E002`).
- **Block define**: `define NAME { <pipeline ops or json fields> }` — spliced inline into field pipelines or `json` schemas by writing the bare identifier `NAME`.

### 2.3 `extension`

Defines typed, target-specific custom pipeline operations. Direct children of `extension <Namespace>` are operation names (no `op` keyword).

- **Call Syntax**: Mandatory `!` prefix in pipelines: `!<Namespace>.<op>` (`E300` if undeclared, `E100` on type mismatch).
- **Signature**: `sig <InType> <OutType>` where types are `doc | str | int | float | bool`, modifiers `(array)` prefix and `?` suffix, or whole-`TypeInfo` generic `T` (`sig T T` preserves exact input `TypeInfo`; `sig T bool` accepts any input and returns `BOOL`). No implicit array mapping.
- **Target Blocks**: `py`, `js`, `go`, `rust`.
- **Target Directives**:
  - `import "<stmt>"` — emitted at parser module top when operation is referenced.
  - `helper <name> { [import "<stmt>";] source #"<code...>"# }` — lazy, deduplicated helper function (emitted into shared runtime for Python `-R`, Go, and Rust; inlined in module utilities for single-file Python and JS).
  - `emit #"<template>"#` — inline code template using placeholders `{{in}}`, `{{out}}`, `{{in_type}}`, `{{out_type}}`.
- **Lazy Emission**: Unreferenced extensions emit nothing; extension-only `.kdl` files are linted but skipped during parser file generation.

```kdl
define BASE-URL="https://example.com"
define EXTRACT-HREF { css "a"; attr "href"; trim }

extension Utils {
    slugify {
        sig str str
        py {
            helper _slug {
                import "import re"
                source #"def _slug(s: str) -> str:\n    return re.sub(r'[^a-z0-9]+', '-', s.lower()).strip('-')"#
            }
            emit #"{{out}} = _slug({{in}})"#
        }
        js { emit #"const {{out}} = {{in}}.toLowerCase().replace(/[^a-z0-9]+/g, '-');"# }
        go {
            import "strings"
            emit #"{{out}} := strings.ToLower({{in}})"#
        }
        rust { emit #"let {{out}}: String = {{in}}.to_lowercase();"# }
    }
}

struct NavLink {
    url { EXTRACT-HREF; fmt "{{BASE-URL}}{{}}" }
    slug { css "a"; text; !Utils.slugify }
}
```

## 3. Structs & Functions (`struct`, `fn`)

### 3.1 Struct Types (`(kind)struct Name { ... }`)

Prefix annotation `(kind)struct` is canonical (legacy `struct Name type="kind"` is accepted).

| Struct Tag | Output Type | Required Directives (`E401`) | Rules & Constraints |
|---|---|---|---|
| `struct` / `(item)struct` | Object / `dict` / `struct` | *(none)* | Default struct type; requires 1+ regular fields |
| `(list)struct` | `list[Item]` | `@split-doc` | Splits document via `@split-doc`; runs field pipelines per item |
| `(dict)struct` | `dict[str, V]` | `@split-doc`, `@key`, `@value` | No regular fields allowed (`E203`) |
| `(table)struct` | Object / `dict` / `struct` | `@table`, `@rows`, `@match`, `@value` | Every regular field **must** begin with `match { ... }` (`E203`) |
| `(flat)struct` | `list[str]` | *(none)* | Optional `keep-order=#true` prop; fields must return `STR` or `STR[]` |
| `(rest)struct` | REST API client | 1+ `@request` (`name=` & `response=`) | Body allows **only** `@doc`, `@request`, `@error[:<suffix>]` (`E203`) |
| `(raw)struct` | Object or `list[Item]` | *(none)* (`@split-doc` optional) | Plain-text `STR` input (no HTML parser). HTML ops (`css*`, `xpath*`, `text`, `attr`, `raw`) forbidden (`E203`). Auto-selects `LIST` if `@split-doc` present, else `ITEM`. |

### 3.2 Struct Directives

| Directive | Allowed In | Formal Syntax & Semantics |
|---|---|---|
| `@doc` | module, `struct`, `fn` | `@doc "<text>"` — emits module/class/function docstring |
| `@init` | `item`, `list`, `dict`, `table`, `flat`, `raw` | `@init { <name> { <pipeline> }; ... }` — precomputes & caches values on instance; referenced as first op in fields via `@<name>` (`self <name>` deprecated) |
| `@pre-validate` | `item`, `list`, `dict`, `table`, `flat`, `raw` | `@pre-validate { assert ["<msg>"] { <predicates> } }` — validates input before `parse()`; raises `SscAssertionError` on failure |
| `@check` | `item`, `list`, `dict`, `table`, `flat`, `raw` | `@check <name> { <pipeline>; to-bool; [fallback #false] }` — emits public boolean method (`is_main(self) -> bool` in Python, `isMain()` in JS, `IsMain()` in Go, `is_main(&self) -> bool` in Rust); pipeline must contain `to-bool` |
| `@split-doc` | `list`, `dict`, `raw` | `@split-doc { <pipeline -> DOC[] \| STR[]> }` — splits input into item nodes/strings |
| `@key` | `dict` | `@key { <pipeline -> STR> }` — extracts dictionary key per split item |
| `@value` | `dict`, `table` | `@value { <pipeline> }` — extracts dict value or table cell value |
| `@table` | `table` | `@table { <pipeline -> DOC> }` — locates `<table>` element |
| `@rows` | `table` | `@rows { <pipeline -> DOC[]> }` — selects row elements from `@table` |
| `@match` | `table` | `@match { <pipeline -> STR> }` — extracts header key from row for `match { ... }` |
| `@request` | all `struct` types | `@request [props] "<curl_or_http>"` — emits HTTP `fetch` / endpoint methods |
| `@error[:<suffix>]` | `rest` only | `@error[:<suffix>] <status> <Schema> [keys...] [k=v ...]` — typed error response rule |

### 3.3 Module-Level Functions (`fn`, `(raw)fn`)

- **Syntax**: `fn <name> { [@doc "..."] <pipeline> }` or `(raw)fn <name> { [@doc "..."] <pipeline> }`
- **Contract**: Emits a standalone function (`snake_case` in Python/Rust, `camelCase` in JS, `PascalCase` in Go) accepting a document/string and returning the inferred pipeline type. Struct directives (`@init`, `@pre-validate`, `@check`, `@split-doc`, `@request`, `@error`) are forbidden (`E203`). `(raw)fn` starts with `STR` and forbids HTML ops (`E203`).

```kdl
struct BookItem {
    @init { card { css ".card" } }
    @pre-validate { assert { css ".card" } }
    @check has-price { css ".price"; to-bool; fallback #false }
    title { @card; css "h2"; text; trim }
}

(list)struct Catalog {
    @split-doc { css-all ".book-row" }
    item { nested BookItem }
}

(dict)struct MetaMap {
    @split-doc { css-all "meta[name]" }
    @key { attr "name" }
    @value { attr "content"; fallback #null }
}

(table)struct SpecsTable {
    @table { css "table.specs" }
    @rows { css-all "tr" }
    @match { css "th"; text; trim }
    @value { css "td"; text; trim }
    weight { match { eq "Weight" } }
}

(flat)struct TagLinks keep-order=#true {
    tags { css-all "a.tag"; attr "href" }
}

(raw)struct PlaylistLines {
    @split-doc { split "\n" }
    line { trim }
}

fn page-title { @doc "Extract H1"; css "h1"; text; trim }
(raw)fn extract-version { re #"version=([0-9.]+)"# }
```

## 4. Pipeline Operations, Type System & Predicates

### 4.1 Unified `TypeInfo` Model

- **Scalar Base Types (`VariableType`)**: `DOCUMENT` (`DOC`), `STRING` (`STR`), `INT` (64-bit), `FLOAT` (64-bit), `BOOL`, `NULL`, `NESTED` (terminal), `JSON` (terminal), `AUTO` (internal inference).
- **`TypeInfo` Modifiers** (replaces legacy `LIST_*` / `OPT_*` types):
  - `array` (`is_array=True`, written `T[]`)
  - `optional` (`is_optional=True`, written `T?`; produced by `fallback #null` in pipelines or `?` in `json`)
  - `dict` (`is_dict=True`, written `dict[K, V]` in `json`, carrying `key_type_info` and `value_type_info`)
- **Initial Pipeline Input**: `DOC` in HTML structs/`fn`; `STR` in `(raw)struct`/`(raw)fn`; or `TypeOf(name)` when starting with `@<name>`.

### 4.2 Pipeline Operations Reference

Format: `op <arg> [opt] : InType -> OutType | rules`

| Category | Formal Syntax Signature (`InType -> OutType`) | Rules, Map Semantics & Exceptions |
|---|---|---|
| **Selectors** | `css "<q>" \| css { "<q1>"; "<q2>"; ... } : DOC -> DOC` | Block pattern-match requires $\ge 2$ queries (no positional arg); tries in order, returns first match |
| | `css-all "<q>" \| css-all { "<q1>"; "<q2>"; ... } : DOC -> DOC[]` | Block pattern-match ($\ge 2$ queries) returns first non-empty element list |
| | `css-remove "<q>" : DOC -> DOC` | Mutates DOM in-place; single positional arg only (no block form) |
| | `xpath "<q>" \| xpath { "<q1>"; "<q2>"; ... } : DOC -> DOC` | Block form $\ge 2$ queries; forbidden in `slax`; JS uses `document.evaluate` |
| | `xpath-all "<q>" \| xpath-all { "<q1>"; "<q2>"; ... } : DOC -> DOC[]` | Block form $\ge 2$ queries; forbidden in `slax` |
| | `xpath-remove "<q>" : DOC -> DOC` | Mutates DOM in-place; single arg only |
| **Extract** | `text : DOC -> STR, DOC[] -> STR[]` | Extracts element text content |
| | `raw [outer\|inner] : DOC -> STR, DOC[] -> STR[]` | Default `outer` (includes element tag); `inner` extracts inner HTML only |
| | `attr "<k>" : DOC -> STR, DOC[] -> STR[]` | Extracts single attribute value |
| | `attr "<k1>" "<k2>" ... : DOC -> STR[], DOC[] -> STR[]` | Multi-attribute extraction ($\ge 2$ args always returns `STR[]`) |
| **String** *(map over `STR` & `STR[]`)* | `trim ["<chars>"] \| ltrim ["<chars>"] \| rtrim ["<chars>"] : STR -> STR, STR[] -> STR[]` | Strips whitespace or custom character set |
| | `normalize-space : STR -> STR, STR[] -> STR[]` | Collapses consecutive whitespace to a single space and trims |
| | `fmt "<template>" : STR -> STR, STR[] -> STR[]` | Replaces `{{}}` placeholder with current string value |
| | `repl "<old>" "<new>" \| repl { "<k1>" "<v1>"; ... } : STR -> STR, STR[] -> STR[]` | Single substring replacement or multi-pair replacement block |
| | `lower \| upper \| unescape : STR -> STR, STR[] -> STR[]` | Case conversion / HTML entity unescaping |
| | `rm-prefix "<s>" \| rm-suffix "<s>" \| rm-prefix-suffix "<s>" : STR -> STR, STR[] -> STR[]` | Strips literal prefix and/or suffix |
| | `split "<sep>" : STR -> STR[]` | Scalar `STR` input only |
| | `join "<sep>" : STR[] -> STR` | Array `STR[]` input only |
| **Regex** | `re "<pattern>" : STR -> STR, STR[] -> STR[]` | Requires **exactly 1** capture group (`E002`). Raises `SscRegexError` on no-match (`<file>:<line>:<col> re-match failed at <Struct>.<field> pattern=<pat>`), caught by `fallback` |
| | `re-all "<pattern>" : STR -> STR[]` | Scalar `STR` only; requires **exactly 1** capture group (`E002`) |
| | `re-sub "<pattern>" "<repl>" : STR -> STR, STR[] -> STR[]` | Regex substitution |
| **Array** | `index <i:int> \| first \| last : T[] -> T` | Supports negative indices (`first` = `0`, `last` = `-1`) |
| | `slice <start:int> <end:int> : T[] -> T[]` | Sub-list slice; supports negative bounds |
| | `len : T[] -> INT` | Returns array length |
| | `unique : STR[] -> STR[]` | Deduplicates string list (preserves order when `keep-order=#true`) |
| **Conversions** | `to-int : STR -> INT, STR[] -> INT[]` | Parses 64-bit integer |
| | `to-float : STR -> FLOAT, STR[] -> FLOAT[]` | Parses 64-bit float |
| | `to-bool : Any -> BOOL` | Converts scalar truthiness to `BOOL` (mandatory in `@check`) |
| **Structured** | `nested <StructName> : DOC -> NESTED, DOC[] -> NESTED[], STR -> NESTED` | **Terminal op** (pipeline ends here). Target struct must be declared above caller (`E302`). `STR` input valid only when target is `(raw)struct` |
| | `jsonify <SchemaName> [path="<gjson>"] : STR -> JSON, STR[] -> JSON[]` | **Terminal op** (pipeline ends here). Parses & projects JSON via `<SchemaName>` (declared above caller, `E302`) |
| **Control** | `filter { <predicates> } : T[] -> T[]` | Retains list elements matching all top-level predicates (implicit `AND`) |
| | `assert ["<msg>"] { <predicates> } : T -> T` | Validates value without changing type; raises `SscAssertionError` on failure (never stripped by `python -O`; default msg `<file>:<line>:<col> assertion failed at <Struct>.<field>`; caught by `fallback`) |
| | `match { <predicates> } : DOC -> DOC` | **Must be first op** in `(table)struct` fields (`E203`); matches `@match` key and extracts `@value` |
| | `fallback <literal \| #null \| {}> : T -> T \| T?` | **Must be last op**. `<literal>` must match pipeline type (`E100`); `#null` marks scalar `STR`/`INT`/`FLOAT` optional (`T?`, `E100` on other types); `{}` requires `T[]` (`E100`) |
| | `@<name> : -> TypeOf(name)` | **Must be first op** (`self <name>` deprecated); reads cached `@init` field (`E301` if undeclared) |
| | `!<Namespace>.<op> : sig In -> Out` | Invokes typed user extension (`E300` if unknown, `E100` on type mismatch) |

### 4.3 Central Parser Guards (`core/expressions.py`)

- **`E100` ("requires a preceding operation")**: Emitted when an operation that reads `parent.body[-1]` is placed at the start of an empty pipeline (`trim`, `ltrim`, `rtrim`, `normalize-space`, `fmt`, `repl`, `lower`, `upper`, `rm-prefix`, `rm-suffix`, `rm-prefix-suffix`, `unescape`, `re`, `re-sub`, `re-all`, `to-bool`, `to-int`, `to-float`, `split`, `join`, `fallback`).
- **`E001` ("requires N argument(s), got M")**: Enforced centrally before per-op handlers (`css-remove`, `xpath-remove`, `attr`, `fmt`, `rm-prefix`, `rm-suffix`, `rm-prefix-suffix`, `split`, `join`, `re`, `re-all`, `re-sub`, `index`, `slice`, `jsonify`, `nested`). Block-form selectors (`css`, `css-all`, `xpath`, `xpath-all`) and `repl { ... }` map blocks accept either 1 positional arg OR a children block.

### 4.4 Predicates & Logic Combinators

- **Logic Combinators**: `not { <predicates> }`, `and { <predicates> }`, `or { <predicates> }`. Top-level children of `filter`, `assert`, `match`, `and`, and `not` combine via implicit `AND`; children of `or` combine via `OR`. Multi-value args inside a single predicate (`eq "a" "b"`) match if **any** value matches.

| Category | Predicate Signatures | Allowed Containers | Input Type Requirement |
|---|---|---|---|
| **String** | `eq <v...>`, `ne <v...>`, `starts <v...>`, `ends <v...>`, `contains <v...>`, `in <v...>`, `re "<pat>"` | `filter`, `assert`, `match` | `STR` (`eq`/`ne` also accept `INT`/`FLOAT`) |
| **Attribute** | `has-attr <a...>`, `attr-eq <a> <v...>`, `attr-ne <a> <v...>`, `attr-starts <a> <v...>`, `attr-ends <a> <v...>`, `attr-contains <a> <v...>`, `attr-re <a> "<pat>"` | `filter`, `assert` *(forbidden in `match`)* | `DOC` / `DOC[]` |
| **Text** | `text-starts <v...>`, `text-ends <v...>`, `text-contains <v...>`, `text-re "<pat>"` | `filter`, `assert` *(forbidden in `match`)* | `DOC` / `DOC[]` |
| **Document** | `css "<sel>"`, `xpath "<sel>"` | `filter`, `assert` *(forbidden in `match`)* | `DOC` / `DOC[]` |
| **Length** | `len-eq <n...>`, `len-ne <n...>`, `len-gt <n>`, `len-lt <n>`, `len-ge <n>`, `len-le <n>`, `len-range <min> <max>` | `assert` **only** (`E203` elsewhere) | `STR` or `T[]` |
| **Regex List** | `re-any "<pat>"`, `re-all "<pat>"` | `assert` **only** (`E203` elsewhere) | `STR[]` |
| **Numeric** | `gt <n>`, `lt <n>`, `ge <n>`, `le <n>` | `assert` **only** (`E203` elsewhere) | `INT`, `FLOAT`, `STR`, or `T[]` |

```kdl
json OfferPayload {
    sku str
    in_stock bool
}

struct ProductPage {
    title {
        css { "h1.product-title"; "h1" }
        text
        normalize-space
        assert "Title too short" { len-ge 3 }
    }
    price {
        css ".price"
        text
        re #"(\d+\.\d{2})"#
        to-float
        assert { ne 0.0 }
        fallback #null
    }
    gallery_urls {
        css-all "img.gallery"
        filter {
            has-attr "src"
            not { attr-contains "src" "placeholder" "spacer" }
        }
        attr "src"
        unique
        fallback {}
    }
    offer {
        css "script#offer-json"
        text
        jsonify OfferPayload path="data.offer"
    }
}
```

## 5. JSON Schemas (`json`, `(array)json`, `(dict)json`)

### 5.1 Declarations, Field Modifiers & GJSON Paths

- **Top-Level Kinds**:
  - `json <Name> { <fields...> }` — JSON object schema.
  - `(array)json <Name> { <fields...> }` — top-level JSON array of objects.
  - `(dict)json <Name> { [@key <ScalarType>;] @value <ValueType>; }` — homogeneous map with dynamic keys (`Python: Dict[K, V]`, `JS: Record<K, V>`, `Go: map[K]V`, `Rust: HashMap<K, V>`; `@key` defaults to `str`).
- **Field Syntax**: `<field_name> <type>[?] [from="<gjson_path>"] [@omitempty] [@skip]`
  - `<type>`: `str | int | float | bool | null | <SchemaRef> | (array)<type> | (dict)[DictName]`
  - `?`: Nullable (`None` / `null` / pointer / `Option<T>`).
  - `@omitempty`: Key may be absent from wire payload (defaults to `None`/zero-value when missing).
  - `@skip`: Validated on wire but omitted from generated output type and projector.
  - `from="<gjson_path>"` (**JSON key alias**): Maps wire key or nested **GJSON path expression** to `<field_name>`. (`path="..."` is accepted with warning `W041`; legacy positional string alias emits `W011`; leading/trailing whitespace in `from=` emits `W040`; malformed dot-path emits `E040`; duplicate field/wire key emits `E041`).
- **GJSON Path Grammar**:
  - Dot-separated object keys (`a.b.c`), escaped literal dot (`\.` for wire key `"a.b"`, written `from=#"a\.b"#` or `from="a\\.b"` in KDL), non-negative array index (`items.0.name`), array count (`items.#` $\to$ `int`), and array element projection (`items.#.name` $\to$ `(array)str`). Filters (`#[...]`), wildcards (`*`), and negative indices are forbidden (`E040`).

### 5.2 Inline JSON Schemas, Inline `@value` Blocks & Synthesized Schema Names

Nested object blocks and dictionary `@value` blocks are recursively hoisted post-order (innermost leaves first) into top-level `JsonDef` nodes ahead of their parent schema.

| Inline Declaration Form | Synthesized `JsonDef` Name | Rules & Validation |
|---|---|---|
| `field { ... }` | `{Parent}{FieldPascal}` | Anonymous inline object (e.g. `User` + `address` $\to$ `UserAddress`) |
| `field ModelName { ... }` | `ModelName` | Explicitly named inline object |
| `field (array)ItemModel { ... }` | `ItemModel` | Inline object array; explicit `ItemModel` name is **mandatory** (anonymous `(array)` raises `E001`) |
| `(dict)json DictSchema { @value { ... } }` | `{DictSchema}Value` | Top-level dict with anonymous inline value block (e.g. `TranslationsValue`) |
| `field (dict)DictName { @value { ... } }` | `{DictName}Value` | Named inline dict field with anonymous `@value` block (e.g. `TranslationValue`) |
| `field (dict) { @value { ... } }` or `(dict)field { @value { ... } }` | `{Parent}{FieldPascal}Value` | Anonymous inline dict field with anonymous `@value` block (e.g. `AnimeResponseTranslationsValue`) |
| `@value ModelName { ... }` / `(ModelName)@value { ... }` | `ModelName` | Explicitly named `@value` object block |
| `@value (array)ItemModel { ... }` / `(array)@value ItemModel { ... }` | `ItemModel` | Array of inline objects in `@value`; `ItemModel` name is **mandatory** (`E001`) |

- **`@value` Modifiers & Validation**: Supports nullable `?` (`@value Model? { ... }`, `(Model?)@value { ... }`, `@value ? { ... }`) and multi-level nested `(dict)` fields. Empty `{}` in `@value` raises `E001`; `@skip` on `@value` with a block raises `E002`; name collisions raise `E001`.
- **Block `define` Expansion**: Bare `UPPER_CASE` block define names inside `json { ... }` expand their child fields inline.
- **Strict Allowlist JSON Projectors**: Generated projectors (`_project_*` / `from_value`) validate container types, extract only declared fields, enforce required/nullable/`@omitempty` contracts, and strip all unmodeled wire keys.
- **KDL Backslash Continuation Caveat**: A single-line `//` comment immediately after `\` consumes the newline and breaks line continuation; if HTTP request fragments (`curl`, `GET`, `POST`, `-H`, `http://`) leak as stray struct fields, the linter emits a continuation diagnostic hint.

```kdl
define AUDIT-FIELDS {
    created_at str @omitempty
    internal_id str @skip
}

(dict)json Translations {
    @key str
    @value {
        title str
        tags (array)str
    }
}

json AnimeResponse {
    AUDIT-FIELDS
    id int from=#"meta.item\.id"#
    tag_count int from="tags.#"
    tag_names (array)str from="tags.#.name"
    author {
        name str
        bio str? @omitempty
    }
    episodes (array)EpisodeItem {
        num int
        air_date str?
    }
    (dict)localized {
        @key str
        @value LocalizedEntry? {
            label str
        }
    }
    extra Translations
}
```

## 6. HTTP & REST (`@request`, `@error[:<suffix>]`)

### 6.1 `@request` Directive

- **Two Execution Modes**:
  1. **HTML / `(raw)struct`**: Emits `fetch` / `async_fetch` constructors that execute the HTTP request, optionally extract `response-path` (joining `list[str]` via `response-join`), and return the parsed struct. Parser class remains transport-agnostic for direct HTML/string input.
  2. **`(rest)struct`**: Every `@request` **requires** `name="<kebab-id>"` and `response="<SchemaName>"` (or `response=#null` for empty/204 responses) (`E001`/`E002`). Emits typed client methods returning monadic `Result` objects (`Ok` / `Err` variants; never throws on mapped errors).
- **Formats**: POSIX `curl` command string, raw `HTTP/1.1` / `HTTP/2` request text, or a scalar `define` name.
- **Properties**: `name="<kebab-id>"`, `response="<SchemaName>|#null"`, `doc="..."`, `response-path="<dot.path>"`, `response-join="<sep>"`.
- **Typed Placeholders (`{{name[:type][[]][?][|style]}}`)**:
  - `name`: lowercase `^[a-z][a-z0-9_-]*$` (`UPPER_CASE` `{{NAME}}` is resolved at compile time from `define`).
  - `type`: `str` (default) | `int` | `float` | `bool`.
  - `[]`: array parameter; `?`: optional parameter (`None` / `undefined` / `Option` omitted when unset).
  - `style` (arrays only, default `repeat`): `repeat` (`?k=1&k=2`), `csv` (`?k=1,2`), `bracket` (`?k[]=1&k[]=2`), `pipe` (`?k=1|2`), `space` (`?k=1%202`).
  - **Constraints**: `[]` and `?` are forbidden in URL path segments (`E002`); `|style` requires `[]` (`E002`).
- **Per-Call Request Options** (applied per-request; headers shallow-merge, client is never mutated):

| Target | Per-Call Option Parameter | Generated Method Naming |
|---|---|---|
| **Python** | `**kwargs: Any` | HTML: `Struct.fetch(client, ...)` / `Struct.async_fetch(client, ...)`; REST: `Api.<snake_name>(client, ...)` |
| **JavaScript** | `opts = {}` | HTML: `Struct.fetch(client, params, opts)`; REST: `Api.<camelName>(client, params, opts)` |
| **Go** | `opts ...sscReqOpt` | HTML: `New<Struct>Fetch(client, ...)`; REST: `New<Struct>().<PascalName>(client, ...)` |
| **Rust** | `opts: Option<&SscRequestOpts>` | HTML: `<Struct>::fetch_with_opts(client, ..., opts)`; REST: `<Struct>::<snake_name>_with_opts(client, ..., opts)` |

### 6.2 `@error[:<suffix>]` Directive (`(rest)struct` only)

Syntax: `@error[:<suffix>] <status:100..599> <SchemaName> ["pos.key"...] [prop.key=val ...]`

- **Explicit Suffix Naming (`@error:<suffix>`)**:
  - `<suffix>` must match `^[A-Za-z_][A-Za-z0-9_-]*$` (`E002`).
  - Emits variant `<PascalStruct>Err<Status><PascalSuffix>` in Python/JS/Go (e.g. `ApiErr404NotFound`) and `Err<Status><PascalSuffix>` on `<PascalStruct>Error` enum in Rust (`ApiError::Err404NotFound`).
- **Automatic Naming (no `:suffix`)**:
  - Extracts the last non-numeric leaf segment from each positional key and property key in declaration order, appending **at most the first 2 leaf keys** in PascalCase to `<PascalStruct>Err<Status>` (e.g. `"data.errors.0.detail"` $\to$ `ApiErr404Detail`; `"a.first" "b.second" third="x"` $\to$ `ApiErr400FirstSecond`).
- **Collision & Duplicate Key Linting (`E400`)**:
  - Duplicate resolved variant names within the same `(rest)struct` emit `E400` (disambiguate with `@error:<suffix>`).
  - The same key must not appear in both positional args and property conditions on a single `@error` (`E400`).
- **Nested Dot-Path Conditions**:
  - Positional args check nested key/index existence (`"error.details.0.code"`).
  - Property args check exact field values (`response.success=#false`, `data.0.type="err"`). All conditions combine via `AND` across Python, JS, Go, and Rust.
- **Safe Runtime Fallthrough**:
  - Matchers evaluate in declaration order (including `@error 200 ...` rules before 2xx success projection). If status and conditions match, but the body is non-JSON or fails `<SchemaName>` projection, the runtime catches the projection error and falls through to try the next `@error` rule, falling back to `UnknownErr` (`Unknown` in Rust) when status is outside `200..299`.

```kdl
define API-HOST="https://api.example.com"
define SEARCH-REQ="curl '{{API-HOST}}/items/{{id:int}}?q={{query:str?}}&tags={{tags:str[]?|csv}}'"
define DELETE-REQ="curl -X DELETE '{{API-HOST}}/items/{{id:int}}'"

struct AjaxSnippet {
    @request response-path="payload.html" response-join="\n" """
    POST /api/render HTTP/1.1
    Host: example.com
    Content-Type: application/json

    {"page": {{page:int}}}
    """
    heading { css "h2"; text; trim }
}

json Item {
    id int
    name str
}

json ApiError {
    error str? @omitempty
}

json ActionError {
    success bool
}

(rest)struct CatalogApi {
    @doc "Catalog REST client"
    @request name="search-items" response="Item" SEARCH-REQ
    @request name="delete-item" response=#null DELETE-REQ
    @error:not-found 404 ApiError error="not_found"
    @error 404 ApiError "error.detail.0.code"
    @error 200 ActionError success=#false "detail.reason"
}
```
