# Inline JSON Schemas and Compiler Hoisting

Accepted: Support deeply nested JSON structures via inline field blocks (`field_name { ... }`, `field_name ExplicitType { ... }`, and `field_name (array)ItemType { ... }`) within parent `json` declarations. To preserve hierarchy without polluting the module namespace or breaking flat-type code generation across target languages (Python `TypedDict`, Go `struct`, Rust `struct`, JavaScript `@typedef`), the compiler hoists inline blocks into standalone `JsonDef` AST nodes ordered ahead of their parent schemas. Anonymous inline blocks synthesize PascalCase names using the `{ParentTypeName}{FieldName}` ancestor chain, and field properties (`from="..."`, `@omitempty`, `?`) mirror scalar fields with full symmetry while accepting `path="..."` as an alias with an informational lint hint.
